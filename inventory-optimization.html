📦 AI-Driven Inventory Optimization & Demand Forecasting

Predictive analytics and automated reorder system for retail supply chain management

The Problem

Retailers lose millions annually due to stockouts (lost sales) and overstocking (high holding costs). Manual inventory management is error-prone and doesn't account for demand variability, seasonality, or supplier lead times. The goal was to build a predictive tool that automates reorder triggers and optimizes safety stock levels.

The Solution

Developed an end-to-end Machine Learning pipeline using Python and Streamlit. Engineered time-series features (lags, rolling averages, temporal patterns) and trained a Random Forest model to forecast 60-day demand with high accuracy. Translated these predictions into actionable supply chain metrics (Safety Stock and Reorder Points) using statistical service levels, creating an interactive dashboard for real-time decision making.

Tech Stack

Python Pandas NumPy Scikit-Learn Streamlit Matplotlib SciPy Git

Key Features

  • Achieved a Mean Absolute Error (MAE) of ~3.8 units per day for individual item forecasting
  • Automated calculation of Safety Stock, dynamically adjusting buffers based on user-defined supplier lead times
  • Implemented statistical service level targeting (configurable from 80% to 99%)
  • Built interactive dashboard allowing users to select any store/item combination and view real-time forecasts
  • Generated actionable reorder points that prevent stockouts while minimizing excess inventory

Methodology

1. Data Preparation: Processed 5 years of daily sales data across 50 items and 10 stores. Handled missing values and created consistent time-series frequency.

2. Feature Engineering: Created temporal features (day of week, month, year), lag features (7, 14, 30 days), and rolling window averages to capture trends and seasonality.

3. Model Training: Trained Random Forest Regressor with time-series cross-validation, achieving MAE of 3.84 units on test data.

4. Inventory Optimization: Applied statistical formulas to calculate Safety Stock (Z-score × σ × √lead time) and Reorder Point (average demand × lead time + safety stock).
